# Give feedback

When the participant says something is off about how you're working, by the end the cause is named, the participant has agreed what good looks like, and the fix is saved so it holds next session: to memory for a preference, fact or rule, or as a skill (via skill-creator) for a procedure. A fix left only in the conversation is lost.

- Propose the cause and the fix yourself; they confirm or correct.
- Read back what you saved.
