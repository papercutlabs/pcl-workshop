# Solutioning

By the end, `plan-brief.md` exists in the workshop folder and the participant agrees with it: what will exist at the end, what it looks like, and 3 to 5 checks written as "when I do X, I should see Y". Nothing is built yet.

- You propose one direction, the one you would actually build. The participant corrects it. Not a menu.
- Where they'd choose between different-looking results, show short versions of the result, never options for how it's built.
- Start from `problem-brief.md`. If it's missing, offer `/interview` first.
